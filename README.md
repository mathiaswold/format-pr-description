# Format PR description

A [Raycast](https://www.raycast.com/) extension that reformats PR descriptions
generated by `gh pr create --fill-verbose` into a cleaner Markdown layout.

`gh` renders each commit as a bold list item with a two-space-indented,
hard-wrapped body:

```
- **Add login flow**
  Introduces the login screen
  and wires up auth.
```

The **Format PR description** command rewrites it into:

```
## Add login flow

Introduces the login screen and wires up auth.
```

Each `- **...**` item becomes a `##` header, indentation is stripped, wrapped
prose is unwrapped into one line per paragraph, and sections are separated by
blank lines. Lists and fenced code blocks are preserved as-is.

## Usage

1. Copy a PR description (e.g. the body produced by `gh pr create --fill-verbose`)
   to your clipboard.
2. Run the **Format PR description** command in Raycast.
3. The reformatted text replaces the clipboard contents, ready to paste.

If the clipboard is empty or contains no `- **...**` sections, the command
shows a notice and leaves the clipboard untouched.

## Format commit message

The **Format commit message** command re-wraps the clipboard so no line is
longer than 72 characters:

```
Adds a retry helper around the client so transient failures are retried instead
of surfacing an error to the caller.
```

becomes

```
Adds a retry helper around the client so transient failures are retried
instead of surfacing an error to the caller.
```

Each paragraph is re-filled from scratch rather than only having its overflow
pushed down, so no line is left unnaturally short. Lines are broken at
whitespace only, which means a URL longer than 72 characters is never split —
it gets a line of its own and overflows it.

Blank lines, the subject line, indentation, list items (with a hanging indent),
headings, block quotes and fenced code blocks all keep their structure, and a
trailing block of git trailers (`Co-authored-by:` and friends) is left verbatim
so its one-trailer-per-line layout survives.

## Development

```sh
npm install
npm run dev    # run the extension in development mode
npm run lint   # lint
npm run build  # build
```

Built with the [Raycast API](https://developers.raycast.com/).
